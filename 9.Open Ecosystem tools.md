# Open Ecosystem Tools

**Open-Source GenAI Module:** Running local LLMs, orchestrating chains, and building lightweight assistants entirely on the open-source stack — Ollama, LM Studio, HuggingChat, Flowise, and LangServe.

---

## Core Ecosystem Stack

- **Ollama:** Framework for running, managing, and serving LLMs locally.
- **LM Studio:** Desktop application for discovering, running, and testing open-source models offline.
- **HuggingChat:** Open-source conversational UI interface powered by open-weights models.
- **Flowise:** Low-code, drag-and-drop interface for building LLM chains and agent workflows.
- **LangServe:** Framework for deploying LangChain runnables and pipelines as production REST APIs.

# Why Run the Open Ecosystem?

> _Open-source tooling trades a managed API for control. The payoff is privacy, cost, and freedom to customize — at the price of running the infrastructure yourself._

---

## Key Benefits

- **Data Stays Local:** Prompts and documents never leave your machine. A fit for PHI, IP, and regulated workloads.
- **No Per-Token Cost:** Once a model is downloaded, inference is free. Iterate and load-test without metering.
- **Full Customization:** Swap models, fine-tune, set system prompts, and shape the stack to your exact use case.
- **Offline & Portable:** Runs air-gapped or on-prem, with no dependency on an external provider's uptime.

# Ollama — Docker for Local Models

> _A CLI-first, client-server runtime: pull a model once, and Ollama runs it as a background service exposing a REST API your apps can call._

---

## How It Works

1. **Client:** CLI · app · IDE plugin
2. **`localhost:11434`:** REST + OpenAI / Anthropic API
3. **Ollama Server:** Background daemon schedules & runs
4. **Model Store (`~/.ollama`):** Weights pulled from the registry

---

## Core Capabilities

- **Model Library:** One-command pulls from a curated registry — Llama, Mixtral, Gemma, Qwen, DeepSeek, Phi.
- **Modelfile:** Bundle weights, system prompt & params like a Dockerfile for reproducible custom models.
- **Drop-in APIs:** OpenAI- and Anthropic-compatible endpoints with JSON schema, tool calling, streaming & embeddings.
- **Runs Anywhere:** macOS, Windows, Linux & Docker; auto GPU (CUDA, Apple MLX); agentic coding via `ollama launch`.

# LM Studio — local LLMs with a real GUI

> _A desktop app over llama.cpp and Apple MLX: discover models, chat, run document RAG, and serve an OpenAI-compatible API — no terminal required._

---

## Core Features & Capabilities

- **Model Discovery:** The Discover tab browses GGUF & MLX models from Hugging Face showing quantization, size, and estimated VRAM before you download.
- **Chat & Document RAG:** Built-in playground for side-by-side model evaluation; chat with your own documents fully offline.
- **Local API Server:** OpenAI- & Anthropic-compatible server on `:1234`, with Python / TS SDKs, the `lms` CLI, and the headless `llmster` daemon.
- **Hardware-Aware:** Auto-selects MLX on Apple Silicon (30–50% faster) or llama.cpp with CUDA / Vulkan on PC GPUs.
- **MCP Client:** Connect MCP servers and tools to local models for tool use with no separate orchestration layer needed.
- **Free, Open Engines:** Free for personal & commercial use; the GUI is proprietary while the llama.cpp and MLX engines are open source.

# Ollama vs. LM Studio

> _Two ways to run models locally: a scriptable CLI-first engine, or a polished desktop app. They complement each other — LM Studio to discover and test, Ollama to script and serve._

---

## Tool Breakdown

- **Ollama** `(CLI-first · scriptable · serves an API)`

  - One-line model pulls from a curated library (llama3, mixtral, phi, gemma).
  - Built-in REST server on localhost:11434 for apps and orchestration.
  - Modelfiles let you bake in system prompts and parameters.
  - Cross-platform; ideal for automation and CI pipelines.

- **LM Studio** `(GUI · model discovery · local server)`
  - Browse and download GGUF models from Hugging Face in-app.
  - Chat UI with parameter sliders and no command line needed.
  - OpenAI-compatible local server for drop-in integration.
  - Great for quick evaluation and comparing quantizations.

# Lab 1 — Run Mixtral / LLaMA via Ollama

---

## Steps & Workflow

1. **Install Ollama:** Download for macOS, Windows, or Linux. Starts a background service.
2. **Pull a model:** Fetch the weights once; cached locally for reuse.
3. **Chat from the CLI:** Interactive REPL straight from the terminal.
4. **Call the local API:** Same models exposed over REST for your apps.

---

## Terminal Commands

```bash
# 1. install, then verify
ollama --version

# 2. pull models (one-time)
ollama pull llama3
ollama pull mixtral

# 3. chat in the terminal
ollama run mixtral
>>> Explain RAG in one sentence.

# 4. call the local REST API
curl http://localhost:11434/api/generate \
  -d '{"model":"llama3",
       "prompt":"Hello!"}'
```

# Interfaces & Orchestration

> _With a model running, these tools add a chat UI, a visual builder, and a production serving layer. Each plugging into your local or hosted endpoints._

---

## Tool Breakdown

- **HuggingChat** `(OPEN CHAT INTERFACE & API)`

  - Open-source ChatGPT-style UI from Hugging Face.
  - Hosted app plus an API for lightweight assistants.
  - Switch between leading open models in one place.

- **Flowise** `(VISUAL LLM APP BUILDER)`

  - Drag-and-drop nodes — no/low code on LangChain.
  - Chains, prompts, memory, retrieval, and tools.
  - Export flows as an embeddable chatbot or API.

- **LangServe** `(SERVE CHAINS AS REST APIS)`
  - Deploys LangChain runnables as production endpoints.
  - Auto-generated schema, docs, and a playground.
  - Built on FastAPI with streaming and batching.

# The Open-Source GenAI Stack

> _Three layers, fully open: a runtime to host models, orchestration to compose logic, and an interface to reach users._

---

---

## Layer Breakdown

- **Interface (HuggingChat):** Chat UIs and lightweight assistants for end users.
- **Orchestration (Flowise · LangServe):** Chains, prompts, memory, and retrieval — built and served.
- **Runtime (Ollama · LM Studio):** Local models providing private, no-cost inference.

---

## Key Takeaways

- **Private Inference:** Local runtimes give you private, free inference.
- **Zero Lock-In:** Open tools cover the whole stack — no proprietary lock-in.
- **Rapid Delivery:** Visual builders and APIs let you ship assistants fast.
- **Modular Stack:** Mix and match: pick the layer that fits each use case.
