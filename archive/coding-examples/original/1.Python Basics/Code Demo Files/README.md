# Day 0 – Python Foundations for LLMs

This folder contains hands-on Python examples for Day 0 of LLM / GenAI training.

## How to run

1. Create virtual environment (recommended)
2. Install dependencies:

pip install -r requirements.txt

3. Run any file:

python 00_hello_world.py

## Goal of Day 0
- Build Python confidence
- Understand data structures used in LLMs
- Prepare for real LLM API calls in Day 1
