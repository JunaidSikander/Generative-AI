## Strings

_Text wraooed in quotes -- immutable sequence of characters_

#### Key ideas

- Created with '' or " " quotes
- Index & Slice like a sequence: `name[0]`, `name[:3]`
- Rich methods: `.upper()`, `.lower()`, `.replace()`, `.split()`
- f-string insert values: `f" Hi, {name}"`
- Immutable - methods return a new string

#### Code Example (`strings.py`):

```python
name = "Ada Lovelace"

print(name.upper())       # ADA LOVELACE
print(name[:3])           # Ada
print(len(name))          # 12

print(name.replace("Ada", "Grace"))
# Grace Lovelace

greeting = f"Hello, {name}!"
print(greeting)           # Hello, Ada Lovelace!

```

## Lists

_Ordered, changable collections written in square brackets_

#### Key ideas

- Hold any mix of items [3, "a", True]
- Zero-indexed; negative indexes count from the end
- Mutable -- add, remove & reorder in place
- Common ops: .append(), .sort(), .slicing[1:3]
- len() gives the count of items

#### Code Example (`lists.py`):

```python
nums = [3, 1, 4, 1, 5]

nums.append(9)           # [3,1,4,1,5,9]
nums.sort()              # [1,1,3,4,5,9]

print(nums[0], nums[-1]) # 1 9
print(nums[1:3])         # [1, 3]
print(len(nums))         # 6

```

## Dictionaries

_Unordered key-value pairs written in curly braces_

#### Key ideas

- Store data as key: value pairs
- Look up by key, not position: `user["name"]`
- Add or update by assigning a key
- `.get(key, default)` avoids missing-key errors
- Loop with `.items()` to get key & value together

#### Code Example (`dictionaries.py`):

```python
user = {"name": "Sara", "age": 28}

print(user["name"])          # Sara
user["city"] = "Karachi"     # add key

for key, val in user.items():
    print(key, "->", val)

print(user.get("phone", "N/A"))
# N/A

```

## Conditional Statements

Run different code depending on whether a test is `True`.

#### Key ideas

- `if`: Runs a block of code when its test is `True`.
- `elif`: Checks another test if the preceding `if` (or `elif`) test fails.
- `else`: Acts as the fallback block when none of the preceding conditions matched.
- Indentation: Standard indentation (4 spaces) defines each block of code.
- Comparison Operators: `==`, `!=`, `<`, `>`, `>=`, `<=`

#### Code Example (`conditionals.py`):

```python
score = 82

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"

print(grade)  # Output: B

```

## Loops

_Repeat a block of code without rewriting it_

#### Key ideas

- `for` iterates over a sequence or `range()`
- `while` repeats as long as a test stays `True`
- `range(n)` yields `0 ... n-1`
- `break` exits early; `continue` skips to next
- **Note**: Always change the `while` condition to avoid infinite loops

### Code Example (`loops.py`)

```python
# for loop
for i in range(3):
    print(i)            # 0 1 2

# while loop
count = 0
while count < 3:
    count += 1

print(count)           # 3
```

## Functions

_Package reusable logic under a name you can call again_

### Key Ideas

- Define with `def name(params):`
- `return` sends a value back to the caller
- Parameters can have default values
- Call by name with arguments: `greet("Ali")`
- Keeps code DRY — write once, reuse often

### Code Example (`functions.py`)

```python
def greet(name, greeting="Hi"):
    return f"{greeting}, {name}!"

print(greet("Ali"))
# Hi, Ali!

print(greet("Sara", "Hello"))
# Hello, Sara!
```
